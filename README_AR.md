# تطبيق صيدلية الرحمة للأندرويد - مشروع البناء

هذا مشروع Android يغلّف ملف نظام الصيدلية HTML المرفق داخل WebView، ويستخدم نطاق WebView آمنًا عبر AndroidX WebKit. يحتوي على إذن الإنترنت والكاميرا واختيار ملف استعادة النسخة الاحتياطية.

## بناء APK دون كمبيوتر (باستخدام GitHub من الهاتف)
1. أنشئ مستودعًا جديدًا على https://github.com/new من متصفح الهاتف.
2. ارفع جميع محتويات هذا المجلد إلى المستودع (وليس ملف ZIP نفسه).
3. افتح تبويب Actions في المستودع وفعّل GitHub Actions إذا طُلب ذلك.
4. اختر `Build Al Rahma Pharmacy APK` ثم `Run workflow`.
5. بعد نجاح البناء، افتح نتيجة التشغيل ثم نزّل Artifact باسم `AlRahma-Pharmacy-APK`.
6. فك ضغط Artifact، وستجد `app-debug.apk`؛ نزّله وثبّته على هاتفك.

## ملاحظات مهمة قبل الاستخدام
- هذا مشروع بناء، وليس APK جاهزًا.
- لأن صفحة النظام تعمل من أصل `https://appassets.androidplatform.net`، قد يتطلب تسجيل Firebase إضافة هذا النطاق إلى Authentication > Settings > Authorized domains في Firebase Console إذا ظهر خطأ نطاق غير مصرح به.
- يجب اختبار تسجيل الدخول والمزامنة والكاميرا واستعادة النسخ الاحتياطية قبل استخدام التطبيق على بيانات العمل الفعلية.
- لا يحذف هذا المشروع بيانات Firestore ولا ينشئ قاعدة بيانات جديدة.
- النسخة الناتجة من GitHub Actions هي Debug APK للتجربة؛ لا تشاركها علنًا ولا تعتمدها كإصدار إنتاج موقّع قبل إعداد مفتاح توقيع خاص وحفظه بأمان.
